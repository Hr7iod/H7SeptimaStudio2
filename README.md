# H7 Септима

Адаптивный сайт студии индивидуальной разработки и поддержки сайтов для малого и среднего бизнеса.

## Запуск

Node.js 22 или новее. Для локального сервера зависимости не нужны.

```powershell
npm run dev
```

Открыть http://127.0.0.1:4173. Готовые файлы сайта находятся в `dist`; сборка не требуется.

## Поведение

- Навигация и FAQ работают без JavaScript.
- Переключатель задачи меняет пояснение и записывает выбор в бриф.
- Бриф проверяет поля и скачивается в UTF-8 на устройство посетителя. Данные не отправляются и не сохраняются на сервере. На странице это указано явно.
- Отправка заявок ещё не подключена: сначала нужен реальный контакт студии или серверный обработчик. Форма не сообщает об успешной отправке.

## Дизайн Cobalt и Vantage

Мини-студия удалена по просьбе пользователя, включая настройки дизайна в брифе. Остались выбор задачи, FAQ, мобильное меню и скачивание брифа.

От Vantage: сине-чёрная поверхность, Geologica и точечный знак H7. От Cobalt: холодные светлые разделы, тонкие линии, синие акценты и кнопки с нижней гранью. Прежний логотип H7 в синей плашке сохранён. Фотографии не используются.

Скрипт point-field.js строит облако из существующей геометрии логотипа, не изображает вымышленные сканы или показатели. Движение можно остановить кнопкой. Анимация также останавливается при наведении, фокусе, уходе за экран и скрытии вкладки. При prefers-reduced-motion показывается статичный кадр; без JavaScript виден SVG-знак. Локальные шрифты Geologica и Golos Text снабжены лицензиями в dist/fonts.

## Проверки

```powershell
npm install
npm run check
node scripts/verify.mjs
node scripts/verify-point-field.mjs
```

Для проверки браузером нужен установленный Chrome; сервер должен работать. В `scripts/verify.mjs` можно задать `CHROME_PATH` и `SITE_URL`.

Публикация Sites описана в `.openai/hosting.json`. Менять `project_id` не нужно.
