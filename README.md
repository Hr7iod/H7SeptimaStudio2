# H7 Септима

Адаптивный сайт студии индивидуальной разработки и поддержки сайтов для малого и среднего бизнеса.

## Запуск

Node.js 22 или новее. Для локального сервера зависимости не нужны.

```powershell
npm run dev
```

Открыть http://127.0.0.1:4173. Готовые файлы сайта находятся в `dist`; сборка не требуется.

## Поведение

- Навигация и FAQ работают без JavaScript.
- Переключатель задачи меняет пояснение и записывает выбор в бриф.
- Бриф проверяет поля и скачивается в UTF-8 на устройство посетителя. Данные не отправляются и не сохраняются на сервере. На странице это указано явно.
- Отправка заявок ещё не подключена: сначала нужен реальный контакт студии или серверный обработчик. Форма не сообщает об успешной отправке.

## Интерактивная мини-студия

На первом экране посетитель выбирает бизнес (магазин, бюро, кафе) и настроение (мягко, смело, строго). Меняются палитра, типографика, тексты и графическая композиция демомакета. «Удивить меня» выбирает другой вариант. «Хочу этот стиль» переносит выбранное направление в скачиваемый бриф, сохраняя уже введённый посетителем текст.

Однократное появление первого экрана и анимированные переходы работают через opacity и transform. При prefers-reduced-motion анимация отключается. Без JavaScript макет виден, переключатели выключены и показано пояснение.

## Материалы

По просьбе пользователя восстановлен прежний знак H7 в синей плашке и словесная часть шрифтом Golos Text. Favicon и SVG-знак также восстановлены. Фотографии с людьми больше не используются на странице. Вместо декоративных изображений работает интерактивный пример интерфейса, явно обозначенный как демонстрационный макет. Вымышленных клиентских проектов, отзывов и метрик нет.

## Проверки

```powershell
npm install
npm run check
node scripts/verify.mjs
```

Для проверки браузером нужен установленный Chrome; сервер должен работать. В `scripts/verify.mjs` можно задать `CHROME_PATH` и `SITE_URL`.

Публикация Sites описана в `.openai/hosting.json`. Менять `project_id` не нужно.
